# Photo-tel

Конфигуратор обоев для экрана блокировки смартфона. Выберите готовые и свои темы, общий светлый или тёмный тон и распределите от 1 до 100 кадров автоматически или вручную.

- [Интерактивное демо](https://dzuba110729.github.io/photo-tel/) показывает настройку заказа, прогресс и три примера из готовой коллекции. Этапы имитируются в браузере без ключей и списаний.
- [Готовая коллекция на Google Диске](https://drive.google.com/drive/folders/1AhgHsHe9-rgtdVOInMNYpi2H0bEsV82q) содержит 100 обоев и `prompts.csv` с именем файла, фактически отправленным промптом и моделью для каждого изображения.

## Локальный запуск

Понадобятся macOS или Linux, Python 3.11+, ключ NanoGPT с доступом к Seedream 5.0 Lite и собственный Google OAuth-клиент. Команды выполняются из корня проекта.

1. Установите зависимости.

   ```sh
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements-app.txt
   ```

2. Создайте ключ в NanoGPT и вставьте его в скрытый запрос. Команда сохранит ключ в `.nanogpt-key` с правами `600`. Также можно задать переменную окружения `NANOGPT_API_KEY` в том же терминале. [Ключи NanoGPT](https://nano-gpt.com/api)

   ```sh
   .venv/bin/python pilot.py --set-key
   ```

3. В своём проекте Google Cloud включите Google Drive API, настройте экран согласия с областью `https://www.googleapis.com/auth/drive.file` и создайте OAuth-клиент **Desktop app**. Если у приложения тип External и статус Testing, добавьте свой аккаунт в Test users. Скачайте JSON клиента и подставьте путь к нему в команду ниже. После подтверждения в браузере токен сохраняется в `.gdrive/token.json`. [Подробности настройки OAuth](DRIVE.md#первое-подключение)

   ```sh
   mkdir -m 700 -p .gdrive
   install -m 600 /path/to/client_secret.json .gdrive/client.json
   .venv/bin/python drive_upload.py --authorize
   ```

4. Запустите сервер и откройте [локальную форму](http://127.0.0.1:8765/). Кнопка **Запустить заказ** отправляет платные запросы после проверки баланса и доступа к Диску. Каждый заказ получает собственную приватную папку в вашем Google Диске.

   ```sh
   .venv/bin/python -m uvicorn wallpaper_app:app --host 127.0.0.1 --port 8765
   ```

## Архитектура

- `wallpaper_ui.html` и `assets/` содержат форму, предпросмотр тона, расчёт тиража, историю и индикаторы прогресса. `wallpaper_app.py` принимает и валидирует заказы через FastAPI.
- `wallpaper_prompts.py` распределяет кадры по темам и варьирует сюжет, композицию, стиль, палитру и свет. `wallpaper_jobs.py` обрабатывает один заказ за раз, до трёх кадров одновременно, и сохраняет прогресс в SQLite. NanoGPT Seedream 5.0 Lite создаёт исходники, а Pillow приводит их к JPEG RGB 1870 × 4063 с качеством 95.
- `drive_upload.py` загружает изображения и CSV с промптами в Google Диск. Заказ готов после сверки состава папки, контрольных сумм и прав доступа. Локальный каталог `orders-data/` хранит SQLite и материалы заказов для возобновления. При потере ответа на платный запрос приложение ждёт ручной сверки с NanoGPT.
- `build_pages.py` собирает демо из той же формы и ассетов, подключая браузерную имитацию из `pages/demo.js`. После установки зависимостей выполните `.venv/bin/python build_pages.py /tmp/photo-tel-preview/photo-tel` и обслужите родительский каталог командой `.venv/bin/python -m http.server 8000 --bind 127.0.0.1 --directory /tmp/photo-tel-preview`. Демо откроется по [локальному адресу](http://127.0.0.1:8000/photo-tel/).

## Проверка на реальных заказах

Один заказ на 72 кадра прошёл от отправки формы до сверки папки за **22 мин 11 с**. NanoGPT списал **$2,52**. В итоговую коллекцию вошли 28 кадров предыдущих запусков, 67 кадров из этого заказа и 5 точечных замен. Для всех 100 JPEG и CSV сверены имена, размеры и контрольные суммы с файлами в Google Диске.

Режим на 100 кадров отдельно проверен с имитацией NanoGPT и Drive API, включая возобновление после сбоя загрузки. По измеренному тарифу $0,035 за кадр ориентир для 100 кадров составляет $3,50.
